Lorem Agency

Un site vitrine moderne d’agence créative fictive conçu pour mettre en avant une interface immersive, des animations fluides et une expérience frontend premium.

Présentation

Lorem Agency est un concept de site d’agence haut de gamme centré sur le storytelling visuel, le motion design et une expérience utilisateur soignée.

Le projet a été pensé pour simuler un véritable site en conditions réelles, avec une attention particulière portée aux animations, à l’équilibre visuel et aux standards modernes du développement frontend.

Fonctionnalités:

Transitions de pages fluides
Animations basées sur le scroll
Effets interactifs au survol
Design responsive
Structure moderne de landing page
Direction artistique premium
Expérience utilisateur orientée motion design

Stack technique:

React
SCSS
Framer Motion
JavaScript

Objectif

Ce projet a été réalisé pour présenter mes compétences en développement frontend dans un contexte d’agence ou de produit digital, avec un fort accent sur la qualité de l’interface, le design d’interaction et la finition visuelle.
